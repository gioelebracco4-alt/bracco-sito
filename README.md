# Sito BraccoBrand — Calore & Design

Sito di Ceramiche Bracco srl (Petralia Soprana): stufe a pellet e a legna, piastrelle, arredo bagno e parquet.

## Struttura

- `index.html` — anteprima con selettore Desktop / Mobile (mostra `sito.html`)
- `sito.html` — il sito completo, con CSS, font, logo e JS incorporati
- `assets/img`, `assets/video` — foto e video usati dal sito
- `sorgente/` — i file sorgente del sito (HTML, CSS, JS, font, logo)
  - `sorgente/build-preview.py` — rigenera `sito.html` e l'anteprima:
    `python3 sorgente/build-preview.py sorgente <cartella-output>`

Per vederlo in locale basta aprire `index.html` (o `sito.html`) nel browser.
